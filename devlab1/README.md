# Лабораторная работа 1. Знакомство с IaaS, PaaS, SaaS сервисами в облаке на примере Amazon Web Services (AWS). Создание сервисной модели.

## Выполнил: Гашимов Ильхам Фаррух оглы

### Основные модели:

#### IaaS (инфраструктура как услуга).
#### PaaS (платформа как услуга).
#### SaaS (ПО как услуга).

### В работе классифицируем ресурсы по:

#### Уровню абстракции (IaaS/PaaS/SaaS).
#### Функциональной категории (IT Tower, Service Family).
#### Типу потребления (Service Usage Type).

### Для каждой строки:
#### Искал Product Code в документации AWS.
#### Анализировал Usage Type (с wildcard % для паттернов, например, %TimedStorage-ByteHrs - хранение данных по времени).
#### Использовал контекст: lineItem/Operation и Description.
#### Выбирал IT Tower и Service Family из стандартных категорий AWS (Management, Compute, Security и т.д., как в отчете коллеги).
#### Гуглил и искал паттерны (например, "AWS Lambda Usage Type GB-Second" - это вычисления в секундах).
#### Учитывал уровень абстракции: CloudWatch - PaaS (мониторинг), Lambda - PaaS (serverless), EC2 - IaaS (инфраструктура).
